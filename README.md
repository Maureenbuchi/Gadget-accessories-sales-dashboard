# Gadget-accessories-sales-dashboard
An excel-based data analysis and dashboard project providing sales insight for gadget and accessories stores across different regions in Nigeria
# DATASET OVERVIEW
The dataset contains the following columns:

Region – Store region (e.g., North Central, South West)

Market – State location

Store – Specific store branch

Trade Date – Date of transaction

Fiscal Period – Quarter of the year

Product – Product type (e.g., Blender, Headphones)

Line of Business – Category (Accessories / Electrical Gadgets)

Day Category – Day type (Workday, Public Holiday, etc.)

Revenue – Total revenue generated

Unit Sold – Quantity sold
